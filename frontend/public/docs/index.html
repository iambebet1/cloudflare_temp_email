Xác thực (Authentication)

Mọi request gọi vào hệ thống đều cần truyền token qua Header x-admin-auth:

x-admin-auth: <YOUR_API_TOKEN>
GET

/admin/mails

Lấy danh sách các email gửi về cho một địa chỉ cụ thể.

Query Parameters

Field Type Bắt buộc Mô tả
address string Yes Địa chỉ email cần lấy tin nhắn (vd: alex123@4amservices.com)
limit integer No Số lượng mail tối đa muốn lấy (mặc định: 10)

Code mẫu bóc OTP (Python)

                                    
    import requests, re, time
  
    BASE_URL = "https://4amservices.com"
    API_TOKEN = "MatKhauAdminCuaBan123@"
  
    def get_otp(email):
        url = f"{BASE_URL}/admin/mails?address={email}" 
        headers = {"x-admin-auth": API_TOKEN}           
        
        for _ in    
  range(20):
            res = requests.get(url, headers=headers).json()
            if res.get("results"):
                mail_text = res["results"][0]["raw_mail"]
                otp = re.findall(r"\b\d{6}\b",          
  mail_text)
                if otp:
                    return otp[0]
            time.sleep(3)
        return None
